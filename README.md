# Rai Thai Spa Gifting

Техническое задание

Разработка сайта для покупки электронных подарочных сертификатов Rai Thai Spa

О компании

Rai Thai Spa — сеть аутентичных тайских SPA-салонов в городах:

* Петропавловск

* Кокшетау

Основная задача сайта — полностью автоматизировать покупку электронных подарочных сертификатов без участия администратора.

⸻

Цель проекта

Создать современный сайт, на котором пользователь сможет за 1–2 минуты:

* ознакомиться с салоном;

* выбрать подарочный сертификат;

* оплатить его онлайн;

* указать данные получателя;

* получить готовый электронный сертификат сразу после оплаты.

Главный принцип сайта — минимум действий, максимум конверсии.

Структура сайта

1. Первый экран

На первом экране разместить:

* красивый баннер;

* логотип Rai Thai Spa;

* короткое описание салона;

* кнопку «Выбрать сертификат».

⸻

2. Краткая информация о салоне

Небольшой блок:

* сеть тайских SPA;

* настоящие мастера из Таиланда;

* SPA-программы и массаж;

* подарочные сертификаты;

* возможность купить сертификат онлайн за несколько минут.

⸻

Основной блок — выбор сертификата

После открытия сайта пользователь сразу переходит к выбору сертификата.

Должно быть два варианта.

Вариант №1

Сертификат на любую услугу

После выбора пользователь сможет:

* выбрать любой массаж;

* выбрать любую SPA-программу;

* выбрать конкретную услугу из списка.

⸻

Вариант №2

Сертификат на сумму

Возможность выбрать сумму сертификата.

Минимальная сумма:

20 000 ₸

Можно сделать:

* фиксированные суммы;

* либо ввод собственной суммы (не менее 20 000 ₸).

⸻

Выбор дизайна сертификата

Перед оплатой пользователь выбирает оформление.

Например:

* универсальный;

* день рождения;

* для нее;

* для него;

* для двоих;

* романтический;

* Новый год;

* 8 марта;

* 14 февраля.

Дизайн должен сразу отображаться в виде превью.

⸻

Данные сертификата

После выбора пользователь заполняет поля:

Отправитель

* имя

Получатель

* имя

Контакт получателя

* телефон

* либо e-mail

Поздравительный текст

Свободное поле.

Дата отправки

Варианты:

* отправить сразу;

* отправить в выбранную дату и время.

⸻

Проверка заказа

Перед оплатой пользователь видит итоговый экран.

Отображается:

* выбранный сертификат;

* выбранный дизайн;

* сумма;

* данные получателя;

* поздравительный текст.

Кнопка:

Оплатить

⸻

Онлайн-оплата

После подтверждения заказа пользователь оплачивает сертификат самостоятельно.

Необходимо реализовать:

* оплату через Kaspi QR;

* возможность подключения других способов оплаты в будущем.

Важное требование:

Покупка должна происходить полностью автоматически, без участия администратора.

⸻

Выдача сертификата

После успешной оплаты система автоматически:

* генерирует электронный сертификат;

* присваивает уникальный номер;

* отображает сертификат на экране;

* предоставляет возможность скачать его;

* отправляет сертификат получателю (SMS и/или e-mail);

* при необходимости отправляет копию покупателю.

Весь процесс должен занимать не более нескольких секунд после оплаты.

⸻

Административная часть

Необходим личный кабинет администратора.

Функционал:

* просмотр всех проданных сертификатов;

* поиск по номеру сертификата;

* поиск по имени получателя;

* поиск по номеру телефона;

* поиск по e-mail;

* просмотр статуса сертификата (активен / использован / отменен);

* просмотр даты покупки;

* просмотр даты использования;

* экспорт списка сертификатов.

⸻

Интеграция с системой учета

Желательно предусмотреть возможность дальнейшей интеграции с CRM/Altegio, чтобы:

* сертификаты автоматически создавались в системе;

* отображался их статус;

* можно было отслеживать использование сертификатов без ручного ввода.

⸻

Требования к интерфейсу

Интерфейс должен быть максимально простым.

Логика покупки должна напоминать процесс оформления заказа в интернет-магазинах (например, «Золотое Яблоко»):

1. Выбор сертификата.

2. Выбор дизайна.

3. Заполнение данных.

4. Проверка заказа.

5. Онлайн-оплата.

6. Автоматическое получение электронного сертификата.

Минимум экранов, понятная навигация и высокая скорость оформления заказа.

⸻

Главная цель проекта

Создать современный сервис, позволяющий приобрести подарочный сертификат полностью онлайн за 1–2 минуты без звонков, переписок и участия администратора, с мгновенной выдачей готового электронного сертификата после успешной оплаты.
